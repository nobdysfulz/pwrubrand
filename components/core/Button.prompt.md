Square-cornered uppercase CTA button — the brand uses hard 90° corners on every button, never a radius. Use it for every action from hero CTAs to form submits.

```jsx
<Button variant="gradient" size="lg" href="/trial" as="a">Try 7-Days Free</Button>
```

Variants: `primary` (solid magenta, default), `gradient` (magenta→violet, reserve for the hero CTA), `dark` (charcoal), `outline` / `outline-brand` / `outline-inverse` (on dark or photo backgrounds), `ghost`. Sizes `sm | md | lg`. Never place two `gradient` buttons in the same section — pair `gradient` with `outline`.
